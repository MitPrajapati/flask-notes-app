# Flask Notes App

A simple Notes Application built using Flask.

## Features

- User Registration
- User Login
- Create Notes
- View Notes
- Session-based Authentication

## Technologies Used

- Python
- Flask
- HTML
- CSS
- SQLite
- SQLAlchemy

## Project Status

Currently implemented:
- Authentication (Login/Register)
- Note Creation
- Note Viewing

Planned features:
- Edit Notes
- Delete Notes
